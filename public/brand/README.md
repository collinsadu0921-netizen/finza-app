# Finza brand assets

- `finza-logo.svg`: transparent, tightly cropped full wordmark for headers, sign-in pages and documents.
- `finza-icon.svg`: transparent symbol-only master for compact navigation and favicon generation.
- `favicon.ico`: browser favicon containing 16, 32 and 48 px sizes.
- `favicon-16x16.png` and `favicon-32x32.png`: browser fallbacks.
- `apple-touch-icon.png`: 180 px Apple touch icon.
- `icon-192.png` and `icon-512.png`: PWA/app icons.

Use the full wordmark for visible branding. Use the symbol-only files for browser tabs and square icon placements.
